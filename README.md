# Analisis-Peramalan-ARIMA

Deskripsi Proyek:
Proyek ini merupakan tugas mata kuliah Teori Peramalan Statistika yang membahas analisis dan peramalan data runtun waktu (time series) menggunakan metode Autoregressive Integrated Moving Average (ARIMA). Analisis dilakukan untuk mempelajari pola data historis, membangun model peramalan, serta mengevaluasi hasil model yang digunakan.

Metode:
Autoregressive Integrated Moving Average (ARIMA)

Tools:
Python (Google Colab)

Konteks Proyek:
Proyek akademik – Mata Kuliah Teori Peramalan Statistika.
